Excited to share my first end-to-end Data Analytics project: Superstore Sales Analytics.

In this project, I worked with a retail Superstore dataset and analyzed sales performance using Python, MySQL, Power BI, and Tableau.

What I did:

- Loaded and explored the dataset with Python
- Checked missing values and dataset structure
- Calculated total sales
- Analyzed sales by category
- Found the top 5 cities by sales
- Created monthly sales analysis
- Wrote SQL queries in MySQL
- Built dashboard files in Power BI and Tableau

Key insights:

- Total records analyzed: 9,800
- Total sales: 2,261,536.78
- Top category: Technology
- Top city: New York City

This project helped me understand how raw data can be cleaned, analyzed, queried, and presented as business insights.
